# GitHub 项目收藏空间

将侧栏原「我的工作空间」更名为「我的 Skills 空间」，增加同级的「我的 GitHub 空间」。沿用暖白纸面、陶土强调色和衬线标题，通过空间切换更新导航、搜索、分类与主要内容。

GitHub 项目通过固定的 GitHub REST API 读取。输入会统一为仓库首页地址；读取名称、简介、README、topics、语言和 Star 等资料，以真实简介和 README 提取用途，以关键词权重推断大致分类。保留编辑入口，避免把自动归类当成不可修改的结论。未找到、访问限额、超时和取消均显示可操作的状态，失败不新增记录。

使用独立的浏览器项目存储，与原有 Skill、附件和同步基线分开。项目可搜索、收藏、编辑、移除，以及 JSON 备份导出和合并恢复。已有连接的 GitHub 凭据仅用于读取固定 GitHub API，不保存进项目或备份；不新增模型服务或 npm 依赖。

用户随后指定的三个项目作为实际初始资料写入静态目录。项目与已初始化标识在一次存储写入中提交，确保首次加入、后续保留编辑、删除不复活，也能在未来增加新的初始条目。

验证包括地址归一化和拒绝外部主机、真实 UTF-8 README、分类、失败保留数据、凭据排除、备份恢复、重复添加、存储空间不足、初始目录迁移，以及桌面和手机浏览器中的完整添加与编辑流程。原有 Skills 测试与 17 份技能同时验证。
