# Agentic Awesome Skills · 智能体技能库

本集合在 Skill Cabinet 中显示为一个条目。完整的 2,872 份 `SKILL.md` 与附件保存在 `library/agentic-skills.tar.xz`，目录可直接在 `catalog.json` 或 `upstream/CATALOG.md` 中检索。

上游技能目录接近 9,000 个文件，超过页面单个 ZIP 的 3,000 条目限制，因此使用内嵌 tar.xz 保存；整体压缩使完整内容也符合 45 MiB 同步限制。页面可以阅读集合入口和目录；要阅读全部技能附件，请先导出本条目的 ZIP，解压外层后，再用支持 tar.xz 的解压工具或 Python 解压 `library/agentic-skills.tar.xz` 到新的空目录。

Windows 上可在已解压的外层目录运行下面的 Python 命令。它会创建新目录，已有同名目录时停止，并跳过上游的两个无效符号链接别名；全部 2,872 份实际技能及普通附件均会解压。命令只用 Python 标准库。

```bash
python -c "import pathlib,tarfile; out=pathlib.Path('agentic-snapshot'); out.mkdir(); a=tarfile.open('library/agentic-skills.tar.xz'); a.extractall(out, members=(m for m in a if m.isfile() or m.isdir()), filter='data'); a.close()"
```

上述命令要求 Python 3.12 或更新版本。上游 `pdf`、`xlsx` 别名指向该提交中不存在的 `pdf-official`、`xlsx-official`，原始别名仍保存在压缩快照与来源记录中，详见 `VETTING.md`。

选择所需技能的完整文件夹，按调用工具的说明使用；收藏本集合不会自动将数千份技能安装到 Codex 或 Claude Code。运行某份技能前，检查其声明的依赖、网络服务、权限和许可证。
