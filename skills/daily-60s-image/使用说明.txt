每日60秒新闻图片 Skill v1.0

用途：获取北京时间当天的真实新闻图片，核对日期和图片内容后直接交付。没有邮箱推送，也不会创建定时任务。

使用方法：
1. 解压，保留 daily-60s-image 文件夹结构。
2. 将该文件夹交给支持 SKILL.md 的智能体，或放入该智能体的技能目录。
3. 对智能体说：“读取 daily-60s-image/SKILL.md，并执行，给我今天的60秒新闻图片。”
4. 运行环境需支持 Python 3.9+、文件读写、网络访问；最终图上日期/内容检查还需要图片查看能力。Python 脚本仅使用标准库，无需邮箱、账号或 API Key。

常用命令（在技能目录执行）：
python scripts/fetch_daily_image.py --output-dir ./output
Windows 也可将 python 替换成 py -3。

测试样例中的图片是 2026-10-20 的结果，只用于展示，不是每天运行时复用的输入。
本压缩包为便携分发包，未替其他智能体自动安装。
