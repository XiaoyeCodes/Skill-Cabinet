# Awesome DESIGN.md -网页设计风格库

这是一个 Skill，内含 84 份参考规范，不会拆成 84 项技能。导出后保留整个目录。

调用时可说：“用这个技能设计一个个人网站，先推荐几种合适的风格让我选。” 或 “用库中的 Claude 风格做一个知识工具落地页。” 未指定风格时，AI 会询问选择或推荐少量候选；已指定时直接采用。

使用 scripts/design_library.py 可离线检索和导出规范，需要 Python 3.9+，仅用标准库。AI 也可直接阅读 catalog.json 与 library 中选中的 DESIGN.md，无需运行脚本。

来源与版本见 source.json，保留 MIT 许可证。参考来自第三方公开网站分析，实际设计使用自己的文案、标识与可用字体。
