AI 日报原文排版 Skill v1.0

用途：获取 AIBase 当天最新日报，提取各条原标题与完整提要，生成可直接打开的 HTML、纯文本和提取 JSON。保留浅米黄刊头、简约线条装饰；不显示重复“AIBase提要”标签，不改写原文，不在每条下方标来源。没有邮箱推送，不创建定时任务。

使用方法：
1. 解压，保留 aibase-daily 文件夹结构。
2. 将该文件夹交给支持 SKILL.md 的智能体，或放入该智能体的技能目录。
3. 对智能体说：“读取 aibase-daily/SKILL.md，并执行，给我今天的 AI 日报成品。”
4. 需要 Python 3.9+、文件读写与网络访问；仅使用 Python 标准库，无需账号、邮箱或 API Key。遇到网站渲染变化时，可由智能体按照随包的浏览器备用流程继续核对提取。

常用命令（在技能目录执行）：
python scripts/aibase_daily.py --out-dir ./output
Windows 也可将 python 替换成 py -3。

默认只取北京时间当天内容，不因为没有更新就偷偷改取前一天。历史测试必须明确指定日期。此包内的10月19日历史样例只用于展示排版，不能视作未来某天的实时结果。
本压缩包为便携分发包，未替其他智能体自动安装；其他智能体仍需具备实际执行工具，不能仅靠读取提示词保证联网成功。
