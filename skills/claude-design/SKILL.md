# 克劳德设计

用 Claude 营销网站的编辑气质与产品展示节奏，设计用户自己的网站。使用独立内容与标识；不把设计分析当作官方品牌规范，也不把静态参考中的功能、价格或模型名称当作当前事实。

## 从参考走向实现

先读取 [references/DESIGN.md](references/DESIGN.md) 的整体视觉、字体、布局及本次需要的组件，再读 [references/implementation.md](references/implementation.md) 的中文与可访问性适配。原始分析完整保留；实际网页采用适配说明中的可用值。

明确用户的产品、读者和主要动作；沿用现有框架与组件。如果已有品牌约束，将本风格融入其布局、字形与表面层次，不自动换掉品牌色。新项目没有指定框架时，用适合交付的简单实现，不因参考页面而安装大型依赖。

## 视觉判断

- 以 `#faf9f5` 奶油色承载大部分阅读区，暖灰墨色承载文字。较深的米色用于少量功能卡片；分隔线细而克制。
- 陶土色 `#cc785c` 用作有限的强调和装饰。小号白字按钮与正文链接使用随包 CSS 中较深的行动色，保证对比度。
- 大标题用常规字重衬线体，留出有节奏的空白；正文、表单与操作用清楚的无衬线。中文标题使用宋体类回退，不照搬拉丁字母的紧行高与负字距。
- 通过奶油底、浅米色块和接近黑色的产品演示区域组织章节。深色块承担代码、界面和流程展示，内容不需要时不用硬塞演示卡。
- 阴影少，用平面色块和细边框建立层次。插画采用原创、统一线宽的物件线稿；真实产品截图可用时优先服务于内容。

可读取 [assets/tokens.json](assets/tokens.json) 作为参数起点，按需引入 [assets/claude-design.css](assets/claude-design.css)。CSS 使用 `.cd-site` 命名空间，避免污染现有项目；不要把它强制覆盖到所有元素。随包 CSS 是通用起点，不取代实际组件的状态与布局设计。

## 做成能用的网站

将参考转为当前项目的语义 tokens、排版层级和主要组件。主行动要有真实去处；演示或占位内容明确标记，不补写虚构用户评价、业务数字或后台成功状态。字体使用现有可用授权资源，缺少专有字体时按适配说明回退，不下载来源不明的字体。

导航、按钮、输入框提供键盘焦点与反馈。手机按内容顺序堆叠，代码滚动局限在卡片内；长中文标题不能挤出视口。尊重减少动态效果偏好。

完成后查看桌面和窄屏实际渲染，检查主要导航、按钮、表单与键盘操作；对修改过的前景背景配对检查对比度。简述使用的布局节奏与关键适配，交付可编辑源码。Git 提交和网站发布按当前用户授权执行。
