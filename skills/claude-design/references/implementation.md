# 克劳德网站风格的实现适配

源材料是对公开营销网站的分析快照。以下规则把它变成用户自有网站的实现起点，不能称为 Anthropic 官方设计系统。

## 保留的视觉特征

奶油底 `#faf9f5`、墨色 `#141413`、正文色 `#3d3d3a`、米色卡面 `#efe9de`、深色演示面 `#181715` 和陶土强调 `#cc785c` 形成主要层次。页面宽度通常不超过 1200px，内容带以 48–96px 的垂直留白相隔。卡片圆角约 12px，按钮约 8px；使用细线，阴影少。

首屏可以是文字与演示物的双列，也可以为更长的内容采用单列。常见节奏是首屏、用途、产品展示、主要行动、页脚，按实际信息调整，不要求凑齐章节。

## 中文与字体

原文提及 Copernicus、Tiempos Headline、StyreneB 等字体名称，不提供字体文件或授权。默认使用系统字体，不发起远程字体请求。若用户已提供可用字体，再引入。

中文标题回退为 `Noto Serif SC, Source Han Serif SC, Songti SC, SimSun, serif`，拉丁标题可用 `Georgia`。中文标题行高 1.25–1.4、正文约 1.7–1.8，字距常规或略正；不要照抄拉丁标题的 1.05 行高、负字距。正文与操作使用系统无衬线。主标题可在移动端约 34px、桌面约 64px 之间流动，长标题允许换行。

## 对比度与交互适配

原分析中的 `#cc785c` 搭配白色小字对比度不足 4.5:1。保留该颜色用于装饰与大面积强调；小号白字主按钮使用 `#a9583e`，悬停与按下加深到 `#8f4733`。正文链接使用深陶土色并加下划线。浅珊瑚色块上优先放墨色正文。

普通辅助文本使用 `#68665f`，比原始 `#6c6a64` 略深，使其在米色卡片上也达到 4.5:1；不要在奶油底上用浅灰 `#8e8b82` 承载需要阅读的小字。深色面正文用 `#faf9f5`、次要文字用 `#c0bdb5`。普通文字至少 4.5:1，大字至少 3:1。浅分隔线用于装饰，不单独承担输入框可见边界；表单轮廓采用 `#8e8272`。

源文档关于“只保留按下态、不写悬停”和 36–40px 触控区域的描述是观察记录。真实项目仍需悬停、焦点、禁用、加载及错误状态，触控目标通常至少 44px。边框、下划线和文字帮助状态识别，不只靠颜色。减少动态效果时关闭非必要位移动画。

## 图形与内容

参考暖纸、笔记、书页、路径、工具等简单线稿，按产品主题原创。不复用 Claude / Anthropic 标识、商标字标或官网营销文案。深色代码或产品演示应反映实际用途；没有真实功能的演示注明示例。

## 验证

至少查看桌面与 390px 左右手机宽度，检查长中文标题、导航折叠、表单反馈和内部代码滚动。模板中不需要的组件可不使用；修改任何颜色后重新计算相邻配对的对比度。使用项目已有的构建或测试命令，不要求联网或安装新框架才能看效果。
