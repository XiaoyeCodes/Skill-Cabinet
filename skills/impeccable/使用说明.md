# Impeccable -网页设计优化

来源：https://github.com/pbakaus/impeccable
版本：4.8.0
提交：d34c87e1a00989ae8dbdd7f6b30b70f23319e860

一套前端设计技能与 24 个命令，覆盖设计方向、评审、排版、交互、响应式与质量打磨。调用时可说“用 Impeccable 检查并改善这个页面的排版和层级”，或按 SKILL.md 使用 /impeccable audit、polish 等命令。

完整保存 Codex 通用技能目录的 63 个文件及其相对路径。导出后保持 reference/、scripts/、agents/ 的布局；根目录就是本技能目录。Windows 启动器为 scripts/impeccable.cmd。原版启动器在首次使用时可能下载其校验清单锁定的引擎；本次收录不运行启动器、不下载引擎、不安装 npm 包或浏览器扩展。没有引擎时可阅读参考资料，但不声称原生检测器已执行。

本包是技能资源，不是整个 Impeccable 开发仓库；上游网页、测试工程与重复的其他宿主输出不重复打包。Apache-2.0 许可和原始指令随包保留，来源清单见 upstream/source.json。
