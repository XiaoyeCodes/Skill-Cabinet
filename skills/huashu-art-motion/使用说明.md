# Huashu Art Motion · 花叔艺术动画

版本：1.2.0。分类：图像与设计。

用于艺术风格动画、解说视频片段、动画拆解、长卷穿越、程序配乐与成片检查。当前快照有 53 张风格配方、53 个场景代码和 9 张解说语法卡，其中 8 种语法附参数化片段与示例。配方包括研究状态与既有实做，实际成熟度见各卡片和索引。

## 使用方法

1. 在 Skill Cabinet 中查看技能指令与附件，或导出完整 ZIP 后解压到新目录。
2. 让调用工具阅读根目录 `SKILL.md`，根据任务选择参考文档；正式制作在独立项目目录进行。
3. 按上游说明准备 uv、FFmpeg 和 Playwright Chromium；各 Python 脚本声明其依赖。首次渲染前需准备浏览器，Windows 兼容性见 `references/compatibility.md`。
4. 例如在解压后的目录运行下面的上游命令，生成梵高场景的一张试渲帧：

```sh
uv run --with playwright python scripts/engine/render.py --solo 09_postimp --stills 0.3 --out 试渲
```

需要语音或图片生成时，再按 `references/capabilities.md`、`references/images.md` 配置。基础代码动画不需要语音或图片服务账号；私人配置应按上游说明保存在安装目录外。口播整片示例有部分自备素材要求，见各目录的 README。
